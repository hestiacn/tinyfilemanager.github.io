PHP5 PASSWORD HASH GENERATOR

password_hash() is a predefined (built-in) function in PHP 5.6 and later versions. It can be verified using password_verify(). [An important characteristic of using hash functions is that they are irreversible. This means that once you convert a password into a hash, you cannot (or it is very difficult to) retrieve the original password from the hash. This is a key security feature of password hashing, as it prevents attackers from easily finding the original password even if the hash is leaked.]
